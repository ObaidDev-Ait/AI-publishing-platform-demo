## 📖 Overview
AI Publishing Platform Demo is a modern full-stack web application that allows users to generate, manage, organize, and publish AI-generated content through a secure dashboard.

The project demonstrates modern software architecture, authentication, role management, database integration, and responsive UI.

---

## ✨ Features

- **AI Content Generation** – Seamless AI-assisted article & post generation.
- **Authentication & Authorization** – Secure user onboarding, sign-in, and token-based security.
- **Role-Based Access Control** – Granular permissions for Admin and standard User roles.
- **Admin Dashboard** – Comprehensive overview for platform analytics, user control, and content management.
- **User Dashboard** – Intuitive portal for content creators to draft, review, and manage work.
- **Content Management** – Full CRUD capabilities for articles, drafts, and categories.
- **Rich Text Editing** – Modern editor support for creating structured, beautiful posts.
- **Responsive Design** – Pixel-perfect experience across desktop, tablet, and mobile devices.
- **Secure API** – Built-in middleware protection, input sanitization, and session management.
- **Modern UI** – Dynamic dark/light mode interface built with modern aesthetic principles.
- **Fast Performance** – Optimized build delivery, fast server-side rendering, and low latency requests.

## 🚀 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ObaidDev-Ait/AI-publishing-platform-demo.git
   cd AI-publishing-platform-demo
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
